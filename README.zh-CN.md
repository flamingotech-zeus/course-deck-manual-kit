# 课程课件与讲师手册生产线

[English](README.md) | [简体中文](README.zh-CN.md)

> 批量生产中文课程课件（含讲师备注与分钟标注），配一套对应的讲师手册。

## 这是什么

> **脱敏说明。** 本 README 已经写成通用版本。技能文件本身可能仍带有内部域名、主机名或本机绝对路径。发布前请先跑一遍扫描（见 `opensource-preflight-audit`），把命中的内容替换掉。

这不是一套幻灯片模板。它围绕的是一条很实际、而模板解决不了的要求：课件要能把规定的课时撑满。

所以每一页都带时间分配，备注里写了这一页要讲什么，让人可以在上台之前就对着时长核一遍。

## 为什么开源

我们办培训、成批产出课程。反复出现的失败是：课件看着是完整的，讲起来提前二十分钟没内容了。

把时间和每一页绑在一起之后，这件事变得可核对。它是一条产出流程，结构通用，不含业务内容。

## 能做什么

- **每页带分钟标注。** 每页写明预计用时，交付前就能把总时长和课时对上。
- **讲师备注。** 课件里带"要讲什么"，不只是"要展示什么"，换一个讲师也能接。
- **配套讲师手册。** Word 版把备注扩写成离开屏幕也能读的内容。
- **批量产出。** 一门 N 节的课当成一套生成，格式和结构在整门课里保持一致，不会一节一节地漂。

## 怎么用

说清课程结构：

- "十节课，每节六十分钟"
- "每节课都要有课件和手册"
- "把整门课一次生成出来"

它会按节产出课件，配对应的手册，时长也会对好。

## 注意与边界

1. **分钟标注是估算。** 它是个规划工具，作用是让超时提前暴露，不构成时间保证。
2. **讲师备注要人工过一遍。** 为了写全而写的备注，和为了讲而写的备注，读起来不一样。
3. **课程内容是输入，不是产出。** 工具负责结构和排版，内容来自你提供的材料。
4. **里面示范的课程是占位符**，应当替换。
